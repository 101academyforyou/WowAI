YourWowAI 隱私權政策

最後更新：2026 年 10 月 4 日

我們收集的資料

  • 帳號資料：帳號名稱、顯示名稱、自我介紹、大頭貼，以及經過加密雜湊的密碼。
  • 聯繫方式（選填）：你自己填寫的 Facebook、Instagram、Threads、LINE、Email、X、GitHub 或個人網站。
  • 你發佈的內容：截圖、影片、貼文文字、工具連結、GitHub 專案連結、AI 工具標籤、留言、按讚、追蹤、封鎖與檢舉紀錄。
  • 登入憑證：用來讓你保持登入的隨機權杖。
  • 推播位址：如果你允許通知，我們會儲存 iPhone 的推播位址，只用來通知你有人 Cool 你的作品、留言、追蹤你，或你追蹤的人發了新作品。登出或刪除帳號時會一併刪除。

我們不會追蹤你在其他 App 或網站上的活動，不使用廣告識別碼，也不會出售你的資料。

資料用途

僅用於提供 YourWowAI 的服務：顯示你的作品、讓其他人與你互動，以及處理檢舉與維護社群安全。

相片與相機權限

只有在你選擇要分享的截圖或影片時，App 才會存取相簿或相機，且只會上傳你選取的檔案。

連動 GitHub

分享作品時，如果你按「匯入」讀取 GitHub 專案，App 會直接向 GitHub 公開 API 查詢該專案（會傳送專案名稱，GitHub 也會看到你的 IP 位址），只讀取公開資訊，不需要也不會取得你的 GitHub 帳號或密碼。這項查詢適用 GitHub 的隱私權政策。

公開範圍

你的帳號名稱、顯示名稱、大頭貼、自我介紹、作品，以及你選擇填寫的聯繫方式，都會對所有人公開。不想公開的聯繫方式請不要填寫，或隨時在「編輯個人檔案」中刪除。

刪除資料

你可以隨時在 App 內刪除帳號，我們會立即刪除你的帳號資料、作品、媒體檔、留言與互動紀錄。
