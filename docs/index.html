// 給用 AI 做東西的人

看看別人用 AI
做了什麼酷工具

YourWowAI 像 IG，但每則分享都是一個用 AI 打造的工具：記帳 App、履歷產生器、番茄鐘……而且一定附上截圖或影片，一眼就看懂它在做什麼。

⚡ 看看有什麼功能 常見問題與支援

// iPhone App 即將登上 App Store

// FEATURES

專為「用 AI 做出來的作品」設計

不是一般的社群，而是讓作品被看見、讓人找到靈感的地方。

📸

一定要有截圖或影片

每則分享至少附一張截圖或一段示範影片，沒有空口說白話。最多 10 個檔案，左右滑動看。

⚡

Cool／Not Cool

沒有愛心，只有 Cool 和 Not Cool。雙擊圖片就是 Cool，誠實的回饋讓作品越做越好。

🔍

探索與搜尋

依 #Claude、#Cursor 等 AI 工具標籤瀏覽，或直接搜尋作品名稱、介紹與其他 Cooler。

🔔

即時通知

有人 Cool 你的作品、留言、追蹤你，或你追蹤的人發新作品時，馬上收到推播。

💬

聯繫我

在個人頁放上 Instagram、Threads、LINE、Email 等聯繫方式，喜歡你作品的人找得到你。

🛡️

友善安全的社群

可以檢舉不當內容、封鎖使用者；被多人檢舉的內容會先隱藏，等待審查。

// SCREENSHOTS

實際畫面

科技風深色介面，在 iPhone 和網頁上都一樣好用。

// HOW IT WORKS

三步驟分享你的作品

附上截圖或影片

從相簿選、直接拍照，或錄一段示範影片。iPhone 的 HEIC 照片會自動轉成大家都看得到的格式。

寫下工具與 AI

填上工具名稱、介紹、試用連結，以及你用了哪些 AI（Claude、Cursor、v0……）。

收到 Cool 與回饋

其他 Cooler 會按 Cool、留言、追蹤你，你會即時收到通知。

// SAFETY & PRIVACY

安全與隱私

社群安全

  • 註冊前需同意使用條款，對令人反感的內容零容忍
  • 任何貼文都能檢舉，任何人都能封鎖
  • 被 3 位使用者檢舉的貼文會先自動隱藏，等待審查

你的資料

  • 不放廣告、不追蹤你、不出售任何資料
  • 可以隨時在 App 內永久刪除帳號與所有內容
  • 詳細內容請看隱私權政策
