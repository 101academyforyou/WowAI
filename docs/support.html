支援與常見問題

找不到答案？到 GitHub Issues 留言給我們。

一、分享作品

怎麼分享我用 AI 做的工具？

點下方中間的「＋」，加入截圖或示範影片，填寫工具名稱、介紹、試用連結與使用了哪些 AI，再按「分享」即可。

可以連動 GitHub 專案嗎？

可以。分享時在「GitHub 專案」貼上 owner/repo 或 github.com 的專案網址，按「匯入」，App 會自動帶入專案名稱、介紹、網站，以及標在 topics 裡的 AI 工具（只會填入還空著的欄位）。分享後貼文會附上 GitHub 按鈕，大家一鍵就能看原始碼。目前支援公開專案，不需要登入 GitHub。也可以在「聯繫我」填上你的 GitHub 帳號。

為什麼一定要附截圖或影片？

YourWowAI 的精神是「讓作品被看見」。附上畫面，大家才能一眼看懂你的工具在做什麼，所以每則分享都至少要有一張截圖或一段影片。

支援哪些檔案？

JPG、PNG、GIF、WebP 圖片，以及 MP4、MOV、WebM 影片。每則最多 10 個檔案，每個 100MB 以內。iPhone 的 HEIC 照片與 HEVC 影片會自動轉成大家都能看的格式。

二、互動

Cool 和 Not Cool 是什麼？

YourWowAI 用 Cool／Not Cool 取代愛心。每個人對每則作品只有一票，可以改票或再按一次取消。雙擊圖片就是 Cool。大家只看得到總票數，看不到是誰按了 Not Cool。

收不到推播通知？

請到 iPhone「設定」→「通知」→「YourWowAI」確認已允許通知。登出後這台裝置不會再收到該帳號的通知，重新登入即可。就算推播關閉，App 下方的「通知」分頁仍會顯示所有通知。

怎麼讓別人聯繫我？

到「個人」→「編輯個人檔案」→「聯繫我」，填上你的社群帳號、GitHub、LINE、Email 等，填了的會顯示在你的個人頁。這些資訊所有人都看得到，請只填你願意公開的。

三、安全

怎麼檢舉不當內容？

點貼文右上角的「⋯」→「檢舉貼文」，選擇原因。檢舉後那則貼文就不會再顯示給你，我們會在 24 小時內處理。

怎麼封鎖使用者？

在對方的貼文「⋯」選單或個人頁按「封鎖」。封鎖後你不會再看到對方的貼文、留言與通知，雙方的追蹤也會解除。可以隨時在對方個人頁解除封鎖。

四、帳號

怎麼刪除帳號？

到「個人」→「編輯個人檔案」→ 最下方「刪除帳號」，輸入密碼後按「永久刪除帳號」。你的作品、媒體、留言、投票與所有資料都會立即永久刪除，無法復原。詳見隱私權政策。

怎麼更換大頭貼？

到「個人」→「編輯個人檔案」，點大頭貼或「上傳大頭貼」，可以從相簿選擇或直接拍照，App 會讓你裁成正方形。
